# 界面资源改写

Phosphor 对设备界面的所有改动都只作用于**数据与常量**：调色板、字形点阵、字符
串指针、菜单表、若干绘制调用点。绘制代码本身一行不动，所以改写后的界面与原厂
走同一条渲染路径，操作逻辑不变。改写工具的共同纪律：改前校验原值、改写幂等
（重复执行不产生二次破坏）、原值不符时跳过并告警。

地址依据与置信度见 [ANALYSIS.md](ANALYSIS.md)。

## 1. 显示模型（为什么只能这么做）

固件按矩形区域渲染：每块区域临时分配 `w × h × 2` 字节缓冲，画完后由
`push_band`（`0x08008E64`）逐像素推到 LCD，随即释放。RAM 里不存在整屏图像，
区域内容推完即丢。两条推论：

- 每个可见像素必经 `push_band`，它是叠加绘制/拦截的唯一可靠位置（画面流就装在
  这里）；
- 任何要长期显示的元素必须让设备重画，别指望显存里留着什么。

## 2. 主题调色板

调色板在 `0x08035850`，每主题 4 字节（+0 次级色，+2 主色，RGB565），固件按主题
号（`0x20001C6A`）索引读取。次级色全固件 4 处引用，主色 35 处。原厂两套主题是
黄/蓝互换。

`tools/set_theme.py` 预设（次级色, 主色）：

| 预设 | theme 0 | theme 1 | 说明 |
|---|---|---|---|
| `phosphor2` | `#78838D` / `#00E5A0` | `#BDBEBD` / `#FFFFFF` | 构建默认 |
| `phosphor` | `#2A3B36` / `#00E5A0` | `#2A3B36` / `#6BFFC4` | 石墨底荧光绿 |
| `amber` | `#3A2E1A` / `#00E5A0` | `#3A2E1A` / `#FFB020` | 强光环境 |
| `ice` | `#24303A` / `#7FD8FF` | `#24303A` / `#E8F6FF` | 冷白高对比 |
| `stock` | 原厂值 | 原厂值 | 还原用 |

```bash
python tools/set_theme.py in.bin --list
python tools/set_theme.py in.bin --preset phosphor2 -o out.bin
python tools/set_theme.py in.bin --primary 00E5A0 --theme 0 -o out.bin
```

`--primary/--secondary` 接 `RRGGBB`。构建默认套用 `phosphor2`，可用 `THEME_PRESET`
覆盖。

## 3. 字形替换

### 3.1 字库布局

中文字库三档，记录定长："3 字节 UTF-8 + 点阵"，行主序、每行 MSB 在左：

| 字号 | 基址 | 步长 | 条目 | 点阵 |
|---|---|---|---|---|
| 12px | `0x080263B5` | 27 | 154 | 12×12 1bpp |
| 16px | `0x080273F3` | 35 | 357 | 16×16 1bpp |
| 20px | `0x0802A4C2` | 63 | 284 | 20×20 1bpp |

ASCII 半角字库由 `draw_char`（`0x080109A4`）内 `tbb` 按字号分派，覆盖
`0x20..0x7E` 共 95 字符：

| 字号 | 基址 | 每字符步长 |
|---|---|---|
| 12px | `0x08022985` | 12 字节（行宽 1B，用高 6 位） |
| 16px | `0x08022DF9` | 16 字节 |
| 20px | `0x080233E9` | 48 字节（行宽 2B，用高 10 位） |

### 3.2 替换与限制

```bash
python tools/set_font.py in.bin --list
python tools/set_font.py in.bin --font SarasaTermSC-Regular.ttf -o out.bin
python tools/set_font.py in.bin --font ... --size 16 --preview 关于
```

- 字符集与顺序不能变：记录定长、按索引取字；
- 只接受 Sarasa Term SC **Regular**：CL/Bold 变体字宽字重不同，替换后字距错位；
- 仓库不带字体，构建时按 `$SARASA_FONT` → 下载目录 `SarasaTerm-TTF-*/` 的顺序
  查找；找不到只跳过字形替换，主题照常套用（两步相互独立）；
- 12px 档 `m`/`v`/`V` 三个字符受 6px 网格限制，工具内用手工点阵覆盖。

## 4. 关于页

### 4.1 字符串

关于页画两行 16px 文本，按语言号（`0x20001C67`，1..8）从两张指针表取串：版本表
`0x080215FC`（步长 8）、型号表 `0x08021600`（步长 8）。`tools/set_about.py`
两种模式：

| 模式 | 做法 | 限制 |
|---|---|---|
| inplace（默认） | 就地覆盖原串，保留结尾 0 | 型号 ≤8 个 ASCII 字符 |
| `--alloc` | 新串写入空闲 Flash（默认 `0x0803FA00`），改 16 个指针 | 长度受显示宽度约束（型号行约 104–112px） |

### 4.2 Logo

原厂在 `0x0800DEBE` 处 `bl 0x0800EA48` 画 FNIRSI 位图（2bpp，120×20，数据
`0x080317CA`）。补丁把该调用改指 `hook_about`，由 `about_logo.c` 逐像素调用
`put_pixel`（`0x0800E680`）画 Phosphor logo，原位图不再绘制；边框、版本号、型号
等其余内容不受影响。钩子点原指令不符时 `patch.py` 自动跳过、保留原厂 logo。

| 项 | 值 |
|---|---|
| 尺寸 | 168 × 54，位于 (135, 50)，关于页右栏居中 |
| 数据 | 双位平面（`logo_wide` 标志字标 + `logo_wide_dot` 绿点），每行 21 字节 |
| 配色 | 主色白 `0xFFFF`，绿点 `0x0F92` |
| 上限 | 宽 ≤170px（右栏约 173px） |

位平面由 `logo/horizon.svg` 光栅化生成。

## 5. 菜单裁剪

设置菜单里的"主题设置"项在统一调色板后失去意义，`tools/trim_theme_menu.py`
把它移出可见区（手动调用，不进流水线）。只动数据与边界常量：

| 对象 | 地址 | 改动 |
|---|---|---|
| 菜单字符串指针表 | `0x08021B74` | 该项移到组尾，其余前移 |
| 按键分派表 | `0x0800D532` | 与槽序同步重排 |
| 滚动上限 | `0x0800A9B0` | `cmp #1` → `cmp #0` |
| 回车分派边界 | `0x0800D52A` | `cmp #6` → `cmp #5` |

## 6. 扁平化

- **装饰条移除**：5 处 `bl 0x0800E94C` 改双 `nop`（`0x0800C2F6` 顶栏立体板、
  `0x0800C85E`/`0x0800C8C2` 第一页竖条、`0x0800D228`/`0x0800D28C` 第二页竖条）。
  ⚠ `0x0800D70A`/`0x0800D8A6` 的条纹是声光页音量/亮度滑条，**不能**当装饰移除；
- **卡片**：未选中色 `movw` 立即数 `0xBDF7`→`0x29A7`（`0x0800C424`）；4bpp 卡片
  模板（`0x0802F544`，459 字节）清零消除浮雕；
- **分割线**：`hook.c` 在每轮渲染任务返回后用 `fill_rect`（`0x0800E73C`）画 4 条
  `0x29A7` 细线（标题栏下横线、波形区/右面板分隔、右面板两条分段线），画在整帧
  之上不会被本帧 UI 覆盖。

## 7. 版本串

`tools/set_version.py` 定位设置页版本字段（`: V1.6\0\0`，自冒号起 8 字节），去掉
冒号后空格再写入新串，正文 ≤6 字符（要留结尾 0）。固件内 7 种语言各一处，脚本
全部改写；空间不足时整体失败，不做部分写入。

## 8. 校验

- 结构校验：`verify_patch.py` 检查补丁入口、向量、段布局、绝对地址（与界面改写
  是否生效无关）；
- 内容校验：调色板区（`0x08035850`）与字库区可按固定偏移逐字节比对；
- 最终以设备屏幕或抓屏输出为准——字形与配色是视觉结果。

```bash
python tools/verify_patch.py firmware/PHOS_V1.6R36.bin \
    --sym tools/fw/phosphor_patch.sym \
    --hook-site 0x0801A7BC --orig 0x08008EE0
```

## 9. 约束汇总

| 约束 | 原因 |
|---|---|
| 版本串 ≤6 字符 | 字段共 8 字节，含结尾 0 |
| inplace 型号 ≤8 ASCII 字符 | 可用字节为原串长度 +1 |
| 字库字符集与顺序不可变 | 定长记录按索引取字 |
| 仅 SC Regular 字体 | 字宽字重 |
| Logo 宽 ≤170px | 右栏宽度 |
| 主题号索引地址不可变 | 调色板读取路径依赖 `0x20001C6A` |
| 装饰点须逐条核原目标 | 相邻调用可能是功能控件（滑条教训） |
| 改写必须幂等 | 工具可能在同一镜像重复执行 |
